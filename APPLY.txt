XTECH AUTOMATION V22 PATCH

Purpose
-------
V22 changes Email OTP delivery from SMTP to the Resend HTTPS API so it works on Render Free.

Apply
-----
1. Stop XTECH with Ctrl + C.
2. Copy the patch files into your xtech-automation-alpha Git working folder.
3. Keep your existing .env and backend/serviceAccountKey.json.
4. Update your local .env:
   RESEND_API_KEY=YOUR_RESEND_API_KEY
   MAIL_FROM="XTECH Automation <no-reply@xtech-automation.com>"
   EMAIL_OTP_EXPIRY_MINUTES=10
   EMAIL_OTP_RESEND_SECONDS=60
   Remove the old SMTP_HOST/SMTP_PORT/SMTP_USER/SMTP_PASS settings if you want.
5. Run:
   npm.cmd test
   npm.cmd start
6. Test one Email OTP locally.
7. Push:
   git add .
   git commit -m "Release XTECH Automation V22"
   git push

Render environment
------------------
NODE_ENV=production
APP_URL=https://xtech-automation.com
RESEND_API_KEY=YOUR_RESEND_API_KEY
MAIL_FROM="XTECH Automation <no-reply@xtech-automation.com>"
EMAIL_OTP_EXPIRY_MINUTES=10
EMAIL_OTP_RESEND_SECONDS=60

Also add the Firebase web config, Gemini key, and Firebase serviceAccountKey.json secret file.
