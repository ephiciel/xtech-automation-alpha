XTECH AUTOMATION V21 DEPLOYMENT PATCH

What V21 changes
----------------
- Makes the Node/Express server compatible with Render by binding to 0.0.0.0.
- Uses Render's PORT environment variable.
- Supports Firebase Admin credentials from /etc/secrets/serviceAccountKey.json.
- Keeps backend/serviceAccountKey.json working locally.
- Updates .env.example for Resend SMTP and no-reply@xtech-automation.com.
- Adds NODE_ENV and APP_URL production settings.
- Updates README, SETUP, CHANGELOG, AI manual, package version, and validation.

How to apply
------------
1. Stop XTECH with Ctrl + C.
2. Copy these patch files into your xtech-automation-alpha Git folder.
3. Keep your existing .env and backend/serviceAccountKey.json.
4. Run:
   npm.cmd install
   npm.cmd test
   npm.cmd start
5. Confirm localhost still works.

Then push:
   git add .
   git commit -m "Release XTECH Automation V21"
   git push

Render settings
---------------
Runtime: Node
Build Command: npm ci
Start Command: npm start
Health Check Path: /api/status

Do not commit:
- .env
- backend/serviceAccountKey.json
